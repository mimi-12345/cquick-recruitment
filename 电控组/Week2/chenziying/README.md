## ROS2三种通信方式对比
| 通信方式 | 模型 | 特点 | 足球机器人典型场景 |
| ---- | ---- | ---- | ---- |
| **话题 Topic** | 发布/订阅，多对多 | 单向、持续数据流，不关心接收方是否在线 | 视觉持续广播球位置；战术模块持续下发底盘速度指令 |
| **服务 Service** | 请求/响应，一对一 | 同步通信，调用一次返回一次结果 | 查询比赛状态、切换攻防模式；本次任务用来清轨迹 `ros2 service call /clear std_srvs/srv/Empty` |
| **动作 Action** | 目标/反馈/结果 | 长时任务，支持反馈进度、可随时取消 | 控制机器人走到目标点位，中途可以终止运动 |

## 差速底盘运动公式
- 底盘线速度：$v = \frac{v_L+v_R}{2}$
- 底盘角速度：$\omega=\frac{v_R-v_L}{L}$
- 转弯半径：$r=\frac{v}{\omega}$

> $v_L$左轮速度，$v_R$右轮速度，$L$轮距；
> linear.x对应底盘线速度v；angular.z对应角速度ω；
> angular.z大于0代表左转，等于0为直行。
